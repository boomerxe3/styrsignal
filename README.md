# Styrsignal

Statisk kopia av [styrsignal.com](https://www.styrsignal.com/) för GitHub Pages.

Ny design: ren HTML/CSS/JS utan byggsteg (`assets/style.css`, `assets/site.js`). Hero-animationen visar en reglersignal som svänger in mot börvärdet, och sektioner tonar in vid scroll. Alla animationer stängs av med `prefers-reduced-motion`. Ursprungligt utseende finns i taggen `baseline-wix`.
